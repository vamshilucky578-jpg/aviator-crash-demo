# Aviator Crash Game

A modern, polished Aviator-style crash game demo with a Node.js backend, real-time lobby status, and provably fair round generation.

## Features

- Smooth crash-game animation and flying plane
- Betting system and bankroll tracking
- Sound toggle for start, cashout, and crash events
- Win/loss statistics and round history
- Fake-but-structured provably-fair round generation on the backend
- Real-time player count via Socket.IO
- Responsive casino-style UI

## Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express + Socket.IO

## Quick Start

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open http://localhost:3000

## Environment

- PORT: optional, defaults to 3000

## Deployment

This project is ready to deploy to Render, Railway, or any Node.js hosting platform.

### Example Render deploy

- Create a new Web Service
- Connect this repo
- Build command: npm install
- Start command: npm start

## Notes

This is a demo project designed for learning and prototyping. It is not a real-money gambling system.
